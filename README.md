# 无面

一个文字冒险小游戏。你是被骗进山里的新娘，第六天夜里，一个小孩敲响了你的窗户。天亮前要走到石门镇，头班车六点十分。

手机和电脑的浏览器都能玩，存档保存在当前浏览器里。

- 每一节都有编号（No.01–No.25），一共 6 个结局。
- 右上角有线索本、“退一步”和声音开关。
- 背景的“老照片”是用 canvas 画的。

> 含拐卖、邪神崇拜和惊吓情节。故事、人物和地名均为虚构。
> 现实中遇到或怀疑有人被拐卖，请拨打 110。

## 文件

| 路径 | 内容 |
|---|---|
| `index.html` | 游戏本体，由 `build.sh` 生成 |
| `src/a_head.html` `src/b_body.html` | 样式和页面结构 |
| `src/s1_story.js`–`src/s4_end.js` | 故事：暗规矩、每一节、结局和对外接口（剧透警告） |
| `src/d_art.js` | 背景照片 |
| `src/e_ui.js` | 界面、存档、铃声 |
| `src/check.mjs` | 穷举所有选择路径，检查结局都走得到、没有死胡同 |

改完 `src/` 以后：

```sh
./build.sh && node src/check.mjs
```
